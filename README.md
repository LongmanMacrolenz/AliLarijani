# 팩트마크 (FACTMARK) — SNS 발언 신뢰도 인증

> 말에도 신용등급이 있습니다.
> 정치·경제 발언을 **공신력 있는 기관의 발표**와 대조하고, 경제 전망은 **발언 이후 시세의 상승·하락 추이**로 채점해
> **신뢰 점수 · 등급 · 인증서**를 발급하는 서비스의 프로토타입입니다.

이 저장소는 이전 프로젝트를 모두 지우고 새로 시작한 것입니다. (이전 내용은 `main` 브랜치 히스토리에 남아 있습니다.)

## 제품 개념

| | 무료 진단 (퍼널) | 상세 분석 보고서 (유료) |
|---|---|---|
| 신뢰 점수 (100점) · 등급 (S~D) | ✓ | ✓ |
| 기본 인증서 PNG / 인쇄 | ✓ | ✓ |
| 지표별 점수 · 발언별 팩트체크 로그 (기관 출처) | — | ✓ |
| 경제 발언 상승·하락 추이 차트 | — | ✓ |
| 법안·판결·경제·정치 주제별 정확도 · 정정 이력 | — | ✓ |
| 검증번호가 있는 공식 인증서 | — | ✓ |

- **평가 소스**: 계정 소유자가 연동한 Threads · Instagram · X · Facebook의 모든 게시물
- **평가 대상**: 검증 가능한 정치·경제 주장과 시장 전망 (법안·판결 발언 중심, 1.3배 가중). 의견·감상은 제외
- **팩트체크 기준**: 한국은행·통계청·기획재정부·국회 의안정보시스템·법제처·대법원·헌법재판소·선관위 등 **기관 공식 발표만** 사용
- **경제 전망 평가**: 발언 이후 실제 등락의 **폭과 추이**. 발언자가 기간을 제시했으면 그 시점, **제시하지 않았으면 현재 기준**
- **인증서**: 70점(B) 이상은 금·은·동 인장의 *인증서*, 미만은 시상 느낌을 뺀 *평가서*로 발급

자세한 계산식은 [`docs/METHODOLOGY.md`](docs/METHODOLOGY.md), 실서비스로 가기 위한 구조와 법적 검토 사항은 [`docs/ROADMAP.md`](docs/ROADMAP.md)를 보세요.

## 지금 구현된 것 / 아닌 것

**구현됨 (동작하는 프로토타입)**
- 랜딩 → 무료 진단(계정 입력 · 분석 진행 · 점수/등급/인증서) → 유료 보고서 안내 → 샘플 보고서 전체 흐름
- 점수 엔진 (`assets/js/engine.js`) — 순수 함수, 단위 테스트 16개
- 인증서 렌더러 (`assets/js/certificate.js`) — 순수 SVG. 기요셰 무늬 테두리, 모서리 로제트, 등급별 금속 인장(금·은·동·슬레이트), 리본. PNG 저장 · 인쇄/PDF
- 상세 보고서 — 지표 구성, 판정 분포, 주제별 정확도, 시세 추이 차트(호버 툴팁 · 표 보기), 필터 가능한 팩트체크 로그, 개선 포인트
- 모바일 대응

**아직 구현되지 않음 (프로토타입의 한계)**
- ⚠️ **모든 계정·발언·수치는 가상 샘플 데이터**입니다 (`assets/js/data.js`). 실제 인물과 무관하며, 화면과 인증서에 "샘플"로 표기됩니다.
- 실제 SNS 연동(OAuth) · 게시물 수집 · 발언 추출 · 기관 데이터 대조는 없습니다. 샘플에 없는 아이디를 입력하면 그렇게 안내합니다.
- 결제는 연결되어 있지 않습니다 (`checkoutUrl`이 비어 있으면 안내 창이 열립니다).
- 유료 잠금은 화면 구성만 보여줍니다. 실서비스에서는 서버가 결제 확인 후에만 보고서 데이터를 내려줘야 합니다. (프로토타입은 잠금 화면에 실제 데이터를 넣지 않고 흐린 자리표시자만 그립니다.)
- 인증서 발급번호는 데모용 해시이며, 검증 페이지가 없습니다.

## 실행

빌드가 필요 없는 정적 사이트입니다.

```bash
npm start          # = python3 -m http.server 8080  →  http://localhost:8080
npm test           # = node --test  (점수 엔진 단위 테스트)
```

`index.html`이 저장소 루트에 있어 GitHub Pages에 그대로 올릴 수 있습니다.

## 파일 구조

```
index.html              랜딩 + 무료 진단 퍼널
report.html             유료 안내(잠금) / 샘플 보고서(?sample=1)  — ?a=<계정id>
assets/css/styles.css   디자인 시스템 (네이비 · 아이보리 · 골드)
assets/js/config.js     브랜드명 · 요금(가안) · 결제 링크 · 팩트체크 기준 기관
assets/js/data.js       가상 샘플 계정 4종 (등급 S/A/B/D 하나씩)
assets/js/engine.js     점수 엔진 (브라우저 + Node 공용)
assets/js/certificate.js 인증서 SVG 생성 · PNG 변환
assets/js/charts.js     점수 링 · 판정 분포 막대 · 시세 추이 차트
assets/js/common.js     공용(저장/인쇄/공유/결제 창)
assets/js/app.js        랜딩 · 퍼널 로직
assets/js/report.js     보고서 페이지
tests/engine.test.js    엔진 테스트
docs/                   평가 방식 · 로드맵
```

## 바꾸는 법

- **이름 · 요금 · 결제 링크**: `assets/js/config.js` (요금은 가안입니다)
- **가중치 · 등급 기준 · 보정 상수**: `assets/js/engine.js` 상단 상수 → `docs/METHODOLOGY.md`도 함께 수정
- **샘플 데이터 추가**: `assets/js/data.js`의 `fact(...)` / `forecast(...)` 헬퍼로 발언을 추가하면 엔진이 바로 평가합니다
- 웹폰트(Noto Serif/Sans KR, Cormorant Garamond)는 Google Fonts에서 불러옵니다. PNG 저장본은 브라우저 보안상 웹폰트를 쓰지 못해 기기에 설치된 명조/고딕 계열 글꼴로 그려집니다.

## 면책

점수·등급·인증서는 공개 게시물을 기관 발표와 대조해 산출한 알고리즘 평가 결과로, 법적 효력이 없고 투자 권유가 아닙니다.
