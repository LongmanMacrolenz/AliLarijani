# 평가 방식 (Methodology)

`assets/js/engine.js`의 참조 구현과 1:1로 대응하는 명세입니다. 상수를 바꾸면 이 문서와 `tests/engine.test.js`도 함께 고치세요.

## 1. 무엇을 평가하나

| 구분 | 설명 | 예 |
|---|---|---|
| **사실 주장 (fact)** | 기관 발표로 맞고 틀림을 따질 수 있는 정치·경제 주장 | "이 법안은 본회의를 통과했다", "대법원이 파기환송했다", "실업률이 올랐다" |
| **전망 (forecast)** | 지수·환율·부동산 등 시세의 상승/하락 예측 | "코스피는 3개월 안에 오른다", "환율은 내린다" |
| 제외 | 의견·가치 판단·감상·농담, 검증할 공식 자료가 없는 주장 | "이 정책은 최악이다" |

주제(topic)는 `bill`(법안) · `ruling`(판결) · `economy`(경제) · `politics`(정치). **법안·판결 발언은 가중치 1.3**, 나머지는 1.0 (정치·경제 중 법안/판결을 중심으로 본다는 요구 반영).

## 2. 사실 주장의 판정

판정은 **공신력 있는 기관의 공식 발표**만 근거로 합니다. 언론 보도·커뮤니티·모델의 추측은 근거가 될 수 없습니다.

| 판정 | 점수 |
|---|---|
| 사실 | 1.0 |
| 대체로 사실 | 0.8 |
| 일부 사실 | 0.5 |
| 대체로 거짓 | 0.2 |
| 거짓 | 0.0 |
| 검증 불가 | 점수에서 제외 (표본 수 `n`에도 포함하지 않음, `coverage`로만 노출) |

근거 기관 목록은 `assets/js/config.js`의 `authorities`: 한국은행, 통계청(국가데이터처), 기획재정부, 산업통상자원부, 한국부동산원, 한국거래소, 금융위·금감원, 공정위, 국회 의안정보시스템, 법제처, 대법원, 헌법재판소, 선관위, 국제기구(IMF·OECD·세계은행).

## 3. 전망의 평가 — 등락 폭과 추이

입력: 발언 시점부터의 누적 등락률 시계열 `path`(체크포인트)와 현재값 `now`. 시작점은 `day 0 = 0%`.

### 3.1 평가 시점 (기간 규칙)

| 상황 | 평가 시점 | 반영 비중 |
|---|---|---|
| 발언자가 **기간을 제시** (`horizonDays`) 했고 이미 경과 | 그 기간 시점 (체크포인트 사이는 선형 보간). 이후의 되돌림은 보지 않음 | 1.0 |
| 발언자가 **기간을 제시하지 않음** | **현재 기준** (가장 최근 값) | 1.0 |
| 기간을 제시했지만 **아직 경과하지 않음** (pending) | 현재 기준 | **0.5** |

### 3.2 점수

방향 부호 `s = +1`(상승 전망) / `−1`(하락 전망), 평가 시점 누적 등락 `Δ`라 하고 `signed = s·Δ`.

```
endScore   = 0.5 + 0.5 · tanh(signed / 5)          # 5%p면 '분명한' 적중/빗나감 (0.88 / 0.12)
trendShare = 평가 시점까지 체크포인트 중 signed > 0 인 비율 (signed = 0 이면 0.5)
score      = 0.65 · endScore + 0.35 · trendShare
outcome    = signed ≥ +1 → 적중 / signed ≤ −1 → 빗나감 / 그 사이 → 보합
```

- **폭**(`endScore`): 조금 틀린 것과 크게 틀린 것을 구분합니다.
- **추이**(`trendShare`): 끝점만 우연히 맞은 경우보다 과정 내내 방향이 맞은 경우를 높게 봅니다.
- 전망의 주제는 항상 `economy`입니다.

## 4. 지표와 종합 점수

| 지표 | 가중치 | 계산 |
|---|---|---|
| 팩트 정확도 `fact` | 45% | 검증 가능한 사실 주장의 판정 점수 가중평균 (주제 가중치 적용) |
| 전망 적중·추이 `forecast` | 30% | 전망 점수의 가중평균 (주제 가중치 × pending 0.5) |
| 정정·책임성 `correction` | 15% | 틀린 발언(사실 ≤ 0.2 또는 전망 < 0.4) 중 스스로 정정한 비율. 틀린 발언이 없으면 1.0 |
| 출처 명시 `sourcing` | 10% | 검증 가능한 사실 주장 중 게시물에서 공식 출처를 밝힌 비율 |

- 해당 발언이 없는 지표(예: 전망이 하나도 없음)는 빠지고 **남은 지표에 가중치를 비례 재배분**합니다.
- `raw = Σ(지표점수 × 재배분 가중치) × 100`

### 4.1 소표본 보정 (수축)

발언이 적은 계정이 우연히 100점을 받는 것을 막기 위해 중간값 쪽으로 당깁니다.

```
score = (n · raw + K · 50) / (n + K)      # K = 3, n = 점수에 반영된 발언 수
```

예) raw 100, n = 8 → 86.4 / n = 25 → 94.6.

### 4.2 보류

`n < 8` 이면 등급을 매기지 않고 "평가 보류(표본 부족)"로 처리합니다.

## 5. 등급 · 인증서

| 등급 | 점수 | 이름 | 인장 | 문서 |
|---|---|---|---|---|
| S | 90 이상 | 최우수 신뢰 | 금 | 인증서 |
| A | 80 이상 | 높은 신뢰 | 은 | 인증서 |
| B | 70 이상 | 양호 | 동 | 인증서 |
| C | 55 이상 | 주의 | 슬레이트 | 평가서 |
| D | 55 미만 | 신뢰 낮음 | 슬레이트 | 평가서 |

- 인증 기준은 **70점**. 미달이면 제목이 "평가서"로 바뀌고 리본·인증 문구를 쓰지 않아 상장처럼 보이지 않게 합니다.
- 표본 신뢰도: `n ≥ 30` 높음 / `n ≥ 15` 보통 / 그 미만 낮음.
- 발급번호 `FM-YYYY-XXXX-XXX`: 계정·점수·기준일의 해시(데모). **실서비스에서는 서버가 발급·보관**해야 합니다.

## 6. 한계

- 시세는 거시·정치 이벤트 등 외부 요인의 영향을 받으므로 전망 적중이 곧 분석력을 뜻하진 않습니다. 점수는 투자 판단의 근거가 아닙니다.
- 사실 주장 판정의 품질은 *발언 추출* 과 *기관 자료 매칭* 의 정확도에 좌우됩니다 (→ `docs/ROADMAP.md`).
- 기관이 아직 발표하지 않았거나 해석이 갈리는 주장은 "검증 불가"로 두며 점수에서 제외합니다.
